/Pacman game for final project CS 355
Authors: Tessa Masi, Shiqi Tan

This game of Pacman plays 1 round with:
    // 4 ghosts (2 DFS search, 1 random movement, and 1 60/30 DFS, random movement)
    // 4 power pellets
    // ~ 3 fruit
    // a tunnel
    // flashing Pacman sign
    // U WIN / GAME OVER sign
    // 3 lives


To play, use the arrow keys to move in the maze. 
'.' are points 
'O' are power pellets that will allow you to eat the ghosts for a period of time
'B' are fruit that give you points
If you eat all of the points, a "U WIN" display message is printed and the game is terminated.
If you lose all lives, a "GAME OVER" display message is printed and the game is terminated.
